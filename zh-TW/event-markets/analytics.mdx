本頁介紹如何使用 DexBuilder Prediction API 建立市場活動分析。以下示例使用生產環境 API：

```text
https://api.dexbuilder.com
```

公開行情介面不需要認證。開始查詢前，可先透過「發現市場」取得 `market_id`、`event_id`、`condition_id` 和 `token_id`。

```bash
BASE_URL="https://api.dexbuilder.com"
MARKET_ID="<market_id>"
TOKEN_ID="<token_id>"
```

## 最近成交

使用市場成交介面檢視指定市場的撮合成交。返回值是陣列，`price` 和 `size` 以字串返回。

```bash API
curl -G "$BASE_URL/api/v4/prediction/markets/$MARKET_ID/trades" \
  --data-urlencode "limit=100"
```

<Accordion title="回應示例">
  ```json
  [
    {
      "id": "trade-123",
      "market_id": "ge_market-1",
      "condition_id": "ge_condition-1",
      "token_id": "ge_token-yes",
      "outcome": "Yes",
      "side": "BUY",
      "price": "0.4500",
      "size": "10.0000",
      "created_at": 1720000000123
    }
  ]
  ```
</Accordion>

請求下一頁時，使用介面返回的 `cursor` 查詢參數。

## Token 價格與 Ticker

使用最新價格介面取得市場某一方的目前價格：

```bash API
curl "$BASE_URL/api/v4/prediction/tokens/$TOKEN_ID/price"
```

需要最佳買價、最佳賣價和最近成交價時，使用 Ticker 介面：

```bash API
curl "$BASE_URL/api/v4/prediction/tokens/$TOKEN_ID/ticker"
```

<Accordion title="Ticker 回應">
  ```json
  {
    "token_id": "ge_token-yes",
    "best_bid": "0.4400",
    "best_ask": "0.4600",
    "last_price": "0.4500",
    "timestamp": 1720000000123
  }
  ```
</Accordion>

## 價格歷史

使用價格歷史介面繪製 Token 歷史價格。 `from` 和 `to` 是毫秒級 Unix 時間戳。

```bash API
curl -G "$BASE_URL/api/v4/prediction/tokens/$TOKEN_ID/price_history" \
  --data-urlencode "interval=1h" \
  --data-urlencode "from=1720000000000" \
  --data-urlencode "to=1720036000000"
```

<Accordion title="回應示例">
  ```json
  {
    "history": [
      {
        "p": "0.4500",
        "t": 1720000000000
      },
      {
        "p": "0.4700",
        "t": 1720003600000
      }
    ]
  }
  ```
</Accordion>

## K 線

使用 K 線介面取得受支援幣種的分時價格和成交量資料。

```bash API
curl -G "$BASE_URL/api/v4/prediction/tokens/BTC/candlesticks" \
  --data-urlencode "interval=1m" \
  --data-urlencode "limit=100"
```

可用週期和返回欄位以 OpenAPI 參考為準。對於介面聲明為字串的數值欄位，應按字串處理，避免精度損失。

## 市場與事件聚合

可使用 Event 和 Market 介面建立市場列表，並在應用層計算分析指標：

- `GET /api/v4/prediction/events` 取得事件列表，支援 cursor 分頁。
- `GET /api/v4/prediction/markets` 取得市場列表，支援按 `event_id`、`slug`、`condition_id` 和 `tag_slug` 等條件篩選。
- `GET /api/v4/prediction/markets/{market_id}/trades` 提供用於計算成交量和活動指標的成交明細。

DexBuilder 不提供 Polymarket `data-api` 中的 `/oi`、`/holders` 或 `/live-volume` 介面。DexBuilder 集成中不要使用這些外部地址。

## 即時分析

即時看板可以訂閱 Prediction Markets WebSocket，並結合 REST 快照：

```text
wss://broker.dexbuilder.com/ws/dex-builder/prediction
```

公開頻道包括 `pred.trades`、`pred.depth`、`pred.bbo`、`pred.status`、`pred.cpi`、`pred.candlestick` 和 `pred.oc_price`。訂閱參數和返回消息格式請參閱「即時資料」與「公共頻道」。
