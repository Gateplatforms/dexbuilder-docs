根據 Market ID 或 slug 查詢公開市場資料時，請區分兩種回應模型。按 ID 查詢回傳字串 `title` 及 `start_time`、`end_time`；按 slug 查詢可回傳多語言 `question` 和交易限制等擴充欄位。兩種介面均無需認證。

生產環境 Base URL：

```text
https://api.dexbuilder.com
```

## 查詢 Market

根據 Market ID：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/markets/<market_id>"
```

根據 slug：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/markets/slug/<market_slug>"
```

## 按 ID 查詢的回應

以下示例對應 `GET /api/v4/prediction/markets/{market_id}`。`outcomes[].token_id` 可直接用於對應 Token 的價格和訂單簿介面。

```json Example
{
  "market_id": "market-123",
  "event_id": "event-123",
  "slug": "example-market",
  "title": "Will the outcome occur?",
  "condition_id": "0xabc...",
  "status": "active",
  "closed": false,
  "accepting_orders": true,
  "enable_order_book": true,
  "start_time": 1782666000,
  "end_time": 1782752400,
  "outcomes": [
    { "outcome": "Yes", "token_id": "token-yes", "clob_token_id": "token-yes", "price": "0.50" },
    { "outcome": "No", "token_id": "token-no", "clob_token_id": "token-no", "price": "0.50" }
  ]
}
```

## 欄位說明

| 欄位 | 說明 |
| --- | --- |
| `market_id`、`event_id` | Market 與所屬 Event 的 ID |
| `title` | 市場標題，字串 |
| `condition_id` | 結算 Condition ID |
| `outcomes` | 每項包含字串 `outcome`、`token_id`、`clob_token_id` 和 `price` |
| `status`、`closed` | 市場狀態 |
| `accepting_orders`、`enable_order_book` | 交易與訂單簿開關 |
| `best_bid`、`best_ask`、`last_trade_price` | 盤口與最近成交摘要 |
| `start_time`、`end_time` | Unix 秒級時間戳 |

## 按 slug 查詢的回應

`GET /api/v4/prediction/markets/slug/{slug}` 使用另一種 MarketDetail 模型，可包含多語言 `question`、`min_order_size`、`tick_size`、`neg_risk`、`resolved_at` 等欄位。其欄位及類型以[按 Slug 查詢市場](/zh-TW/event-markets/rest/query-market-by-slug)為準，不應與按 ID 查詢的回應混用。

## 使用 Outcome Token

從 `outcomes[].token_id` 取得 Token ID 後，可以繼續呼叫價格、Ticker 和訂單簿介面：

```bash cURL
TOKEN_ID="<token_id>"

curl "https://api.dexbuilder.com/api/v4/prediction/tokens/$TOKEN_ID/order_book?depth=20"
curl "https://api.dexbuilder.com/api/v4/prediction/tokens/$TOKEN_ID/price"
curl "https://api.dexbuilder.com/api/v4/prediction/tokens/$TOKEN_ID/ticker"
```

API 已直接在 `outcomes` 數組中回傳 Token ID，無需額外解析 JSON 字串形式的 Token 清單。

## 查詢所屬 Event

使用響應中的 `event_id` 查詢父級 Event：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/events/<event_id>"
```

Market 公開資料無需認證；下單、持倉、帳戶等私有介面需要認證。
