查詢持倉詳情。

## 介面欄位

**請求路徑:** `GET /api/v4/broker/prediction/positions/{position_id}`

### 請求參數

| 欄位 | 位置 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- | --- |
| `KEY` | header | string | 是 | Broker API Key |
| `Timestamp` | header | string | 是 | Unix 秒級時間戳，與閘道時間差不超過 60 秒 |
| `SIGN` | header | string | 是 | 依實際外部請求路徑、Query 與 Body 產生的 HMAC-SHA512 十六進位簽名 |
| `sub_user_wallet_addr` | header | string | 是 | 目標終端使用者錢包地址；閘道會驗證該錢包屬於目前 Broker |
| `position_id` | path | string | 是 |  |

### 成功回應

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `available_size` | string |  |
| `avg_open_price` | string |  |
| `claimable_amount` | string |  |
| `event_id` | string |  |
| `locked_size` | string |  |
| `outcome` | string |  |
| `position_id` | string |  |
| `position_value` | string |  |
| `settlement_status` | string |  |
| `size` | string |  |
| `token_id` | string |  |
| `updated_at` | integer |  |
| `won` | boolean |  |

介面定義的回應狀態：`200`, `400`, `401`, `503`。

欄位定義依目前介面契約；實際錯誤資訊以回應為準。
