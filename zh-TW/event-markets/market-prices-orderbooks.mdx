每個 Market Outcome 都由一個 Token 表示。先透過「發現市場」或「市場詳情」取得 `outcomes[].token_id`，再使用 Token ID 查詢價格和流動性資料。

本頁介面均為公開市場資料介面，無需認證。生產環境 Base URL：

```text
https://api.dexbuilder.com
```

## 訂單簿

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/tokens/<token_id>/order_book?depth=20"
```

`depth` 為可選查詢參數；實際回傳的檔位以 `bids`、`asks` 為準。

```json Example
{
  "token_id": "token-yes",
  "condition_id": "0xabc...",
  "bids": [
    { "price": "0.48", "size": "100.00" }
  ],
  "asks": [
    { "price": "0.52", "size": "80.00" }
  ]
}
```

| 欄位 | 說明 |
| --- | --- |
| `token_id` | Outcome Token ID |
| `condition_id` | Market Condition ID |
| `bids`, `asks` | 買賣深度，每檔包含 decimal string 格式的 `price` 與 `size` |

此訂單簿回應不提供快照時間或 Hash。若需要判斷報價是否仍適用，請重新查詢訂單簿；不要將 Ticker 的時間戳視為訂單簿快照時間。

目前 API 沒有批量 Order Book 介面，如需多個 Token 的訂單簿，應分別請求。

## 最新 Token 價格

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/tokens/<token_id>/price"
```

```json
{
  "token_id": "token-yes",
  "price": "0.50",
  "side": "BUY",
  "timestamp": 1782753357257
}
```

`price` 表示該 Outcome Token 的最新成交價，不是最佳買價或賣價。沒有可用成交記錄時，`price` 為 `""`、`side` 為 `""`，`timestamp` 為 `null`。

## Token Ticker

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/tokens/<token_id>/ticker"
```

```json
{
  "token_id": "token-yes",
  "last_price": "0.50",
  "best_bid": "0.48",
  "best_ask": "0.52",
  "timestamp": 1782753357257
}
```

`last_price`、`best_bid`、`best_ask` 分別表示最新成交價、最佳買價和最佳賣價；任一資料不可用時，對應欄位為 `null`。`timestamp` 是回傳的有效價格資料中最新的來源時間；沒有可靠時間時為 `null`，不是伺服器回應時間。

## 批量 Token 價格

透過逗號分隔的 Token ID 查詢，單次最多支援 100 個不同 Token：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/tokens/prices?token_ids=token-yes,token-no"
```

```json
{
  "items": [
    { "token_id": "token-yes", "price": "0.50", "timestamp": 1782753357257 },
    { "token_id": "token-no", "price": "0.50", "timestamp": 1782753357257 }
  ]
}
```

不存在或目前不可見的 Token 會被忽略，回傳順序保持與請求中的有效 Token 順序一致。

批量介面同樣回傳最新成交價。可見 Token 尚無可用成交記錄時，該項的 `price` 為 `""`、`timestamp` 為 `null`。

## 價格歷史

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/tokens/<token_id>/price_history?interval=1h&from=1782666000000&to=1782752400000"
```

| 參數 | 說明 |
| --- | --- |
| `interval` | `5m`、`15m`、`1h`、`4h`、`1d` |
| `from` | 開始時間，Unix 毫秒 |
| `to` | 結束時間，Unix 毫秒 |

單次查詢時間範圍最多 14 天。

```json
{
  "history": [
    { "t": 1782666000, "p": 0.485 },
    { "t": 1782669600, "p": 0.500 }
  ]
}
```
