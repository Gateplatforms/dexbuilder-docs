## Base URL

```text
https://api.dexbuilder.com
```

公開行情 REST 介面使用 `/api/v4/prediction`，無需認證。私有交易、持倉與帳戶介面使用 `/api/v4/broker/prediction`。請以 Broker API Key 簽名，並在 `sub_user_wallet_addr` 傳入目標使用者錢包地址。詳見 [Broker API Key 與簽名](/zh-TW/api-reference/common/broker-authentication) 和 [代表使用者存取](/zh-TW/api-reference/common/sub-user-wallet)。私有 WebSocket 頻道使用獨立的 [Broker WebSocket 認證](/zh-TW/event-markets/websocket/authentication) 流程。

## 介面存取模型

| 介面類型 | 是否需要認證 | 典型能力 |
| --- | --- | --- |
| 市場發現 | 否 | 事件、市場、標籤 |
| 市場資料 | 否 | 價格、Ticker、訂單簿、歷史資料、K 線 |
| 交易 | 是 | 下單、查詢訂單、撤單 |
| 帳戶 | 是 | 持倉、資產、餘額、費率、個人成交 |
| 結算 | 是 | 平倉、領取、資金處理 |

## 分頁

清單介面使用游標分頁：

```json
{"items":[],"next_cursor":"opaque-cursor"}
```

將上一頁回傳的 `next_cursor` 原樣作為下一頁的 `cursor`。不要自行解析或修改游標。

## 時間約定

- 事件與市場日期欄位通常使用 Unix 秒；
- `from`、`to` 等範圍參數通常使用 Unix 毫秒；
- K 線、價格歷史、訂單和帳戶生命週期時間通常使用 Unix 毫秒。

## 多語言欄位

部分文本欄位使用語言對象回傳：

```json
{"en":"Yes","cn":"是","tw":"是"}
```

## 數值欄位

價格、數量、成交額、餘額、手續費等金額類欄位通常以字串回傳。建議使用 Decimal 精度處理，避免二進制浮點誤差。

## 狀態欄位

Market 的 `status` 描述市場狀態；REST 訂單的 `status` 使用 `processing`、`open`、`matched`、`canceled`、`failed`。WebSocket 訊息的 `type` 表示推送訊息類型。請分別依市場、REST 訂單及 WebSocket 頻道的定義解析，不要共用一套狀態枚舉。

## 標準錯誤

```json
{"label":"INVALID_ARGUMENT","message":"invalid request"}
```

| HTTP 狀態 | 說明 |
| --- | --- |
| `400` | 請求參數或 Body 無效 |
| `401` | 私有介面認證失敗 |
| `404` | 資源不存在或目前不可見 |
| `503` | 上游或服務暫時不可用 |
