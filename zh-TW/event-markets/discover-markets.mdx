本頁介紹如何查找和篩選公開 Event 與 Market。市場發現和公開市場資料介面無需認證。

生產環境 API Base URL：

```text
https://api.dexbuilder.com
```

除介面另有說明外，Event 和 Market 的時間欄位使用 Unix 秒級時間戳。Event 的 `title`、`description` 和 Tag `label` 可回傳多語言物件；Market 的 `question` 和 `outcomes[].outcome` 也使用多語言物件。Market 清單回傳摘要，按 ID 或 slug 查詢回傳詳情。

## Events

Event 用於將一個或多個相關 Market 組織在一起。

### 根據 ID 查詢 Event

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/events/<event_id>"
```

### 根據 slug 查詢 Event

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/events/slug/<event_slug>"
```

Event 詳情常用欄位：

| 欄位 | 說明 |
| --- | --- |
| `event_id` | Event 唯一標識 |
| `slug` | URL 友好的 Event 標識 |
| `title` | 多語言 Event 標題對象 |
| `description` | 多語言 Event 描述對象 |
| `markets` | Event 下的 Market 摘要 |
| `markets_has_more` | 內嵌 Market 是否還有更多資料 |
| `active`, `closed` | Event 生命週期狀態 |
| `start_date`, `start_time`, `end_date`, `closed_time` | Event 時間欄位 |
| `volume` | Event 成交量，使用 decimal string |
| `tags` | Tag 摘要 |

```json Example
{
  "event_id": "event-123",
  "slug": "example-event",
  "title": { "en": "Example event" },
  "active": true,
  "closed": false,
  "markets": [],
  "markets_has_more": false
}
```

### Event 清單

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/events?limit=20&active=true&closed=false&sort=start_date&ascending=true"
```

支援的主要 Query 參數：

| 參數 | 說明 |
| --- | --- |
| `limit` | 回傳數量，範圍 1–100 |
| `cursor` | 上一頁回傳的 `next_cursor` |
| `sort` | `start_date`、`start_time`、`end_date` 或 `closed_time` |
| `ascending` | 是否升序 |
| `event_id` | 按 Event ID 篩選 |
| `slug` | 按 Event slug 篩選 |
| `tag_slug` | 按 Tag slug 篩選 |
| `active`, `closed` | 按生命週期狀態篩選 |
| `start_date_min`, `start_date_max` | 開始時間範圍，Unix 毫秒 |
| `end_date_min`, `end_date_max` | 結束時間範圍，Unix 毫秒 |

響應：

```json Example
{
  "items": [
    {
      "event_id": "event-123",
      "slug": "example-event",
      "title": { "en": "Example event" },
      "active": true,
      "closed": false,
      "volume": "12500.50",
      "tags": [
        { "tag_id": "sports", "slug": "sports", "label": { "en": "Sports" } }
      ]
    }
  ],
  "next_cursor": "eyJvZmZzZXQiOjIwfQ"
}
```

當 `next_cursor` 非空時，將它原樣作為下一次請求的 `cursor`：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/events?limit=20&cursor=<next_cursor>"
```

## Markets

Market 是實際可交易的問題，每個 Market 包含一個或多個 Outcome Token。

### 根據 Market ID 查詢

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/markets/<market_id>"
```

### 根據 slug 查詢

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/markets/slug/<market_slug>"
```

市場清單回傳 Market 摘要；按 ID 或 slug 查詢回傳 Market 詳情。三者均使用多語言 `question`、多語言 `outcomes[].outcome` 和 Unix 秒級 `start_date`、`end_date`。從 `outcomes[].token_id` 取得 Token ID 後，可繼續查詢價格和訂單簿。

| 欄位 | 說明 |
| --- | --- |
| `market_id` | Market 唯一識別碼；後續請求應原樣使用回傳值 |
| `event_id` | 所屬 Event ID |
| `slug` | Market slug |
| `question` | 多語言市場問題物件 |
| `condition_id` | Condition ID |
| `outcomes` | Outcome 清單；每項包含多語言 `outcome` 和 `token_id` |
| `status`、`closed` | Market 狀態 |
| `best_bid`、`best_ask`、`last_trade_price` | 盤口和最近成交摘要 |
| `start_date`、`end_date` | Market 時間，Unix 秒；無值時為 `null` |

以下為 Market 摘要範例；詳情還可回傳交易限制和結算欄位：

```json Example
{
  "market_id": "ge_42_7",
  "event_id": "ge_42",
  "slug": "example-market",
  "question": { "en": "Will the outcome occur?" },
  "condition_id": "ge_condition",
  "status": "active",
  "closed": false,
  "start_date": 1782666000,
  "end_date": 1782752400,
  "outcomes": [
    { "outcome": { "en": "Yes" }, "token_id": "ge_yes" },
    { "outcome": { "en": "No" }, "token_id": "ge_no" }
  ]
}
```

### Market 清單

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/markets?limit=20&active=true&closed=false&tag_slug=sports"
```

主要參數：

| 參數 | 說明 |
| --- | --- |
| `limit` | 回傳數量，範圍 1–100 |
| `cursor` | 上一頁回傳的 `next_cursor` |
| `market_id` | Market ID |
| `event_id` | 所屬 Event ID |
| `slug` | Market slug |
| `condition_id` | Condition ID |
| `tag_slug` | 所屬 Event 的 Tag slug |
| `active`, `closed` | Market 生命週期狀態 |

## Tags

Tag 可用於構建分類篩選：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/tags?limit=20&cursor=<cursor>"
```

```json
{
  "items": [
    { "tag_id": "sports", "slug": "sports", "label": { "en": "Sports" } }
  ],
  "next_cursor": "eyJvZmZzZXQiOjIwfQ"
}
```

## 目前 API 範圍

目前 Prediction API 提供 Event、Market、Tag、公開市場成交和 Token 市場資料等能力。未在 DexBuilder API 合同中定義的第三方專用介面不應作為正式集成依賴。
