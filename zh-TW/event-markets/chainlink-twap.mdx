DexBuilder 透過 Prediction Markets WebSocket Broker 的公開 CPI 頻道提供配置的參考價格更新。本頁介紹由 Chainlink TWAP 支援的週期如何透過 Broker 訂閱。

## 連接地址

```text
wss://broker.dexbuilder.com/ws/dex-builder/prediction
```

Event Contracts 使用：

```text
wss://broker.dexbuilder.com/ws/dex-builder/event-contracts
```

## 訂閱 TWAP 週期

Prediction Markets 使用 `pred.cpi` 頻道；Event Contracts 使用 `ec.cpi` 頻道。

```json
{
  "t": 1720000000123,
  "id": "cpi-1",
  "op": "subscribe",
  "ch": "pred.cpi",
  "payload": {
    "items": [
      {
        "symbol": "btcusdt",
        "interval": "chainlink_twap_60s"
      }
    ]
  }
}
```

部署配置可能透過 `5m`、`15m` 和 `4h` 等週期別名使用同一來源。具體可用週期以目前環境配置為準。

## 返回消息

```json
{
  "t": 1720000000124,
  "trace_id": "trace-1",
  "type": "update",
  "ch": "pred.cpi",
  "err": null,
  "result": {
    "symbol": "btcusdt",
    "interval": "chainlink_twap_60s",
    "price": "100000.10",
    "price_timestamp": "1720000000123",
    "ts": 1720000000123
  }
}
```

價格和時間戳按照消息協議分別以字串或整數返回。不要根據返回消息推斷資料源，資料源由週期配置決定。

## 訂閱規則

- CPI 是公開頻道，不需要認證；
- `symbol` 和 `interval` 必填；
- 未在部署中配置的週期可能會被服務端拒絕；
- 使用相同頻道和 payload 搭配 `op: "unsubscribe"` 取消訂閱。

完整消息結構和重連行為請參閱「WebSocket 協議」「公共頻道」和「即時資料」。
