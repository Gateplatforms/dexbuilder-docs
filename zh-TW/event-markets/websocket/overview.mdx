預測市場 WebSocket API 提供公開行情資料和需要認證的帳戶更新。

## 連線

```text
wss://broker.dexbuilder.com/ws/dex-builder/prediction
```

同一產品的頻道可共用一條連線。預測市場使用 `pred.*` 前綴，事件合約使用 `ec.*` 前綴。

## 頻道分組

- 公共頻道：`pred.trades`、`pred.depth`、`pred.bbo`、`pred.status`、`pred.cpi`、`pred.candlestick`、`pred.oc_price`
- 私有頻道：`pred.orders`、`pred.usertrades`、`pred.positions`、`pred.settlements`

公共頻道無需認證，私有頻道需要 Broker API Key 簽名。請參閱[WebSocket 協議](/zh-TW/event-markets/websocket/protocol)、[公共頻道](/zh-TW/event-markets/websocket/public-channels)和[私有頻道](/zh-TW/event-markets/websocket/private-channels)。
