此頁記錄面向 Broker 的能力上線資訊。具體接入方式及參數以連結的 API 文件為準。

<Update label="2026-11-10" description="加密貨幣 K 線">
  ## 新增加密貨幣 K 線查詢

  事件市場提供公開的幣種 OHLCV K 線介面 `GET /api/v4/prediction/crypto/candlesticks`。新接入建議使用幣種代碼 `symbol`；`tag_id` 暫時保留相容，兩者必須且只能提供其中一個。時間邊界及 `history[].t` 使用 Unix 秒；`interval=all` 不保證回傳全部歷史。請參閱[查詢加密貨幣 K 線](/zh-TW/event-markets/rest/query-candlesticks)。
</Update>

<Update label="2026-11-10" description="Broker API 支援">
  ## 事件市場更新日誌

  事件市場已支援 Broker 使用 Broker API Key 存取私有 REST 能力。Broker 可代表旗下使用者呼叫相關介面，並透過 `X-User-Wallet-Address` 指定使用者錢包。公開行情介面仍可直接存取。

  接入前請閱讀[Broker API Key 與簽名](/zh-TW/api-reference/common/broker-authentication)及[事件市場 API 概覽](/zh-TW/event-markets/api/overview)。
</Update>
