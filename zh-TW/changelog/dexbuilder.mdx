<Update label="2026-11-10" description="平台 API 上線">
  ## DexBuilder 平台 API 更新日誌

  DexBuilder 平台 API 已提供面向 Broker 的資產配置、使用者查詢、充值和提現能力。Broker 使用 Broker API Key 呼叫平台介面；代表旗下使用者存取時，透過 `X-User-Wallet-Address` 指定使用者錢包。

  接入前請閱讀[Broker API Key 與簽名](/zh-TW/api-reference/common/broker-authentication)、[平台 API 概覽](/zh-TW/api-reference/dexbuilder/overview)及[平台 API 認證](/zh-TW/api-reference/dexbuilder/authentication)。
</Update>
