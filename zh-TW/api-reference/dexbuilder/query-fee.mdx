查詢按鏈計算的固定充值和提現手續費。

<Note>
  使用 Broker API Key 呼叫。此介面查詢 Broker 配置，無需提供 `X-User-Wallet-Address`。 認證規則見[Broker API 認證與簽名](/zh-TW/api-reference/common/broker-authentication)。
</Note>

## 使用說明

- 回應中的 `network` 標識對應網路；`deposit_fee` 與 `withdraw_fee` 為 USDT 計價的固定金額，並非百分比費率。呼叫時須提供 `x-perp-device-type`。
