查詢資產支持的充值和提現網路。

<Note>
  使用 Broker API Key 呼叫。此介面查詢 Broker 配置，無需提供 `X-User-Wallet-Address`。 認證規則見[Broker API 認證與簽名](/zh-TW/api-reference/common/broker-authentication)。
</Note>

## 使用說明

- 回應列出資產可用的網路配置。`network` 為具體網路標識，`vm` 表示 EVM 或 Solana；實際支援情況以回應為準。
- `min_deposit` 和 `min_withdraw` 使用可讀 Token 單位。未配置最低提現額時，`min_withdraw` 可能省略。呼叫時須提供 `x-perp-device-type`，取值見[平台 API 認證](/zh-TW/api-reference/dexbuilder/authentication)。
