查詢資產支持的充值和提現網路。

<Note>
  使用 Broker API Key 呼叫。此介面查詢 Broker 配置，無需提供 `sub_user_wallet_addr`。 認證規則見[Broker API 認證與簽名](/zh-TW/api-reference/common/broker-authentication)。
</Note>

## 使用說明

- 當前主要提供 USDT 的 Ethereum 網路；`min_deposit` 和 `min_withdraw` 是可讀的 token 數量，非鏈上最小單位。
