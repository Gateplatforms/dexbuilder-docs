按 `chain` 和 `address` 查詢該錢包是否已在當前 Broker 開戶，已開戶時返回對應的 `user_id` 和 `broker_uid`。

需要專案方 Broker API Key 的 `dex_builder` 唯讀或讀寫權限。錢包透過 Query 引數指定，認證規則見[Broker API Key 與簽名](/zh-TW/api-reference/common/broker-authentication)。

## 使用說明

- 開戶前使用 `registered` 判斷該地址的開戶狀態。
- [註冊並綁定 Perp](/zh-TW/api-reference/dexbuilder/users-register)後，使用同一組 `chain` 和 `address` 回查，並核對使用者標識。
- `registered=false` 時，`user_id` 和 `broker_uid` 可省略。

## 呼叫示例

```http
GET /api/v4/dexbuilder/users/resolve?chain=solana&address=<USER_WALLET_ADDRESS> HTTP/1.1
Host: api.dexbuilder.com
KEY: <BROKER_API_KEY>
Timestamp: <UNIX_SECONDS>
SIGN: <SIGN>
```

按實際外部路徑和 Query 引數生成 `SIGN`。可參考[獲取開戶待簽名文案](/zh-TW/api-reference/dexbuilder/users-sign-message)的 Python 示例，將路徑改為 `/api/v4/dexbuilder/users/resolve`。
