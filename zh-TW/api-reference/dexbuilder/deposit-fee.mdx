估算終端使用者的充值手續費。

<Note>
  使用 Broker API Key 呼叫，並在請求頭提供 `sub_user_wallet_addr`。網關會校驗錢包與 Broker 的歸屬關係。 認證規則見[Broker API 認證與簽名](/zh-TW/api-reference/common/broker-authentication)。
</Note>

## 使用說明

- 請求體中的 `address` 須為目標使用者已綁定的錢包。`lz_fee` 回傳 USDT 十進制字符串；傳入[獲取充值簽名資料](/zh-TW/api-reference/dexbuilder/deposit-sign-data)時需按 6 位小數轉換為整數，例如 `0.5` 轉為 `500000`。`native_fee` 為鏈原生代幣最小單位整數，直接傳入。
