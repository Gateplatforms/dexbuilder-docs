使用錢包簽名完成當前 Broker 下的使用者開戶和 Perp 綁定，成功後儲存返回的 `user_id` 和 `broker_uid`。

需要專案方 Broker API Key 的 `dex_builder` 讀寫權限，並提供非空的 `Idempotency-Key` 請求頭。認證規則見[Broker API Key 與簽名](/zh-TW/api-reference/common/broker-authentication)。

選填請求頭 `X-Project-ID` 須符合目前 Broker 的有效專案綁定。省略時使用目前有效綁定。

## 註冊步驟

1. 呼叫[獲取開戶待簽名文案](/zh-TW/api-reference/dexbuilder/users-sign-message)，取得 `message` 和 `timestamp`。
2. 使用 `address` 對應的錢包簽署完整的 `message` 原文。
3. 提交 `chain`、`address`、錢包簽名 `sign` 和原文對應的 `timestamp`。
4. 檢查回應的 `code`、`bound` 和 `broker_uid`，並使用[查詢錢包開戶狀態](/zh-TW/api-reference/dexbuilder/users-resolve)回查。

Solana 已驗證的簽名格式為帶 `0x` 字首的 Ed25519 簽名十六進位制字串。對 UTF-8 編碼的簽名原文進行簽名。

EVM 使用 `personal_sign`（EIP-191），提交帶 `0x` 前綴的簽名。

## 冪等與已有使用者

註冊請求必須帶上非空的 `Idempotency-Key`。

同一地址再次註冊會更新使用者記錄，並在尚未綁定時補綁。成功時 `created` 可為 `true`，包括同一地址再次註冊。`bound` 僅在本次新完成 Perp 綁定時為 `true`，已有 `broker_uid` 時為 `false`。

回應中的 `project_id` 是本次使用的專案綁定 ID，`bound_at` 為回應產生時的 Unix 毫秒時間戳。`broker_uid` 可用於核對綁定結果，公開請求使用各介面說明的請求頭。 `X-Gate-User-Id` 由網關在認證後注入後端，客戶端依各介面要求提供 `X-User-Wallet-Address`。

## 請求體示例

```json
{
  "chain": "solana",
  "address": "<USER_WALLET_ADDRESS>",
  "sign": "0x<ED25519_SIGNATURE_HEX>",
  "timestamp": 1700000000
}
```

將示例中的錢包地址、簽名和時間戳替換為本次開戶取得的實際值。請求體的 `timestamp` 使用簽名文案返回的值，請求頭 `Timestamp` 使用本次 API v4 請求的時間戳。

以下示例從環境變數讀取已取得的錢包簽名和文案時間戳，對最終傳送的 JSON 位元組計算 API v4 簽名。

```python
import hashlib
import hmac
import json
import os
import time
from urllib.request import Request, urlopen

path = "/api/v4/dexbuilder/users/register"
body = json.dumps({
    "chain": os.environ["USER_WALLET_CHAIN"],
    "address": os.environ["USER_WALLET_ADDRESS"],
    "sign": os.environ["USER_WALLET_SIGNATURE"],
    "timestamp": int(os.environ["SIGN_MESSAGE_TIMESTAMP"]),
}, separators=(",", ":")).encode()
timestamp = str(int(time.time()))
signing_text = "\n".join([
    "POST", path, "", hashlib.sha512(body).hexdigest(), timestamp,
])
signature = hmac.new(
    os.environ["BROKER_API_SECRET"].encode(),
    signing_text.encode(),
    hashlib.sha512,
).hexdigest()
request = Request(
    "https://api.dexbuilder.com" + path,
    data=body,
    method="POST",
    headers={
        "KEY": os.environ["BROKER_API_KEY"],
        "Timestamp": timestamp,
        "SIGN": signature,
        "Content-Type": "application/json",
        "Idempotency-Key": os.environ["REGISTER_IDEMPOTENCY_KEY"],
    },
)
with urlopen(request, timeout=15) as response:
    print(json.dumps(json.load(response), ensure_ascii=False, indent=2))
```

## 權限錯誤

若返回以下回應，請確認當前 Key 的 `dex_builder` 已開通讀寫權限。`prediction` 和 `event_contracts` 各自具有獨立權限。

```json
{
  "label": "FORBIDDEN",
  "message": "Request API key does not have dex_builder write permission"
}
```
