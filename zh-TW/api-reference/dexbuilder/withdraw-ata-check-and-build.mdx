檢測 Solana ATA 並構建創建交易。

<Note>
  使用 Broker API Key 呼叫，並在請求頭提供 `X-User-Wallet-Address`。網關會校驗錢包與 Broker 的歸屬關係。 認證規則見[Broker API 認證與簽名](/zh-TW/api-reference/common/broker-authentication)。
</Note>

## 使用說明

- 此介面的 `X-User-Wallet-Address` 須為 Solana 錢包地址，不應使用 EVM `0x` 地址。`payer_address` 是使用者已綁定的 Solana 錢包，承擔鏈上 rent 與手續費；`target_address` 是 ATA 所屬 owner。
- 當 `status=0` 時，須先簽名並廣播回傳的 base64 `tx_data` 再提現；當 `status=1` 時，ATA 已存在且 `tx_data` 為空。廣播失敗後可重新查詢。
