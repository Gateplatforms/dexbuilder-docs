使用私有頻道 `ec.orders` 和 `ec.usertrades` 追蹤訂單生命週期與成交，使用 `ec.positions` 和 `ec.settlements` 追蹤帳戶狀態。

## 連線位址

```text
wss://broker.dexbuilder.com/ws/dex-builder/event-contracts
```

## 訂閱

請使用 Broker API Key 簽名，並在 `auth.wallet_address` 傳入目標使用者的錢包地址。詳見 [Broker WebSocket 認證](/zh-TW/event-contracts/websocket/authentication)：

```json
{"t":1720000000123,"id":"orders-1","op":"subscribe","ch":"ec.orders","payload":{"all":true},"auth":{"method":"broker_api_key","key":"YOUR_BROKER_API_KEY","sign":"HEX_SIGNATURE","wallet_address":"<USER_WALLET>"}}
```

## 推送內容

訂單包含識別碼、方向、價格、數量、狀態和時間戳；使用者成交包含成交、訂單、角色、費率、成交價格、數量和確認狀態；持倉包含數量、平均價格、結算狀態、可用數量、鎖定數量和可領取金額。本文不描述標記價格欄位。

## 狀態恢復

WebSocket 提供事件推送，不能取代 REST 查詢。連線或重新連線後：

1. 訂閱所需的私有頻道。
2. 透過對應的 REST 介面查詢訂單、成交、持倉和帳戶目前狀態。
3. 使用識別碼和時間戳套用後續 WebSocket 更新。

錢包地址須與產生簽名時使用的地址一致。
