查詢資金流水。

## 介面欄位

**請求路徑:** `GET /api/v4/broker/event_contracts/account_book`

### 請求參數

| 欄位 | 位置 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- | --- |
| `KEY` | header | string | 是 | Broker API Key |
| `Timestamp` | header | string | 是 | Unix 秒級時間戳，與閘道時間差不超過 60 秒 |
| `SIGN` | header | string | 是 | 依實際外部請求路徑、Query 與 Body 產生的 HMAC-SHA512 十六進位簽名 |
| `sub_user_wallet_addr` | header | string | 是 | 目標終端使用者錢包地址；閘道會驗證該錢包屬於目前 Broker |
| `limit` | query | integer | 否 |  |
| `cursor` | query | string | 否 |  |

### 成功回應

| 欄位 | 型別 | 說明 |
| --- | --- | --- |
| `items` | AccountBookItem[] |  |
| `items[].amount` | string |  |
| `items[].condition_id` | string |  |
| `items[].created_at` | integer |  |
| `items[].currency` | string |  |
| `items[].direction` | string |  |
| `items[].related_order_id` | string |  |
| `next_cursor` | string |  |

介面定義的回應狀態：`200`, `400`, `401`, `503`。

欄位定義依目前介面契約；實際錯誤資訊以回應為準。
