事件合約 WebSocket API 提供公開行情資料和需要認證的帳戶更新。

## 連線

```text
wss://broker.dexbuilder.com/ws/dex-builder/event-contracts
```

同一產品的頻道可共用一條連線。事件合約使用 `ec.*` 前綴。

## 頻道分組

- 公共頻道：`ec.trades`、`ec.depth`、`ec.bbo`、`ec.status`、`ec.cpi`、`ec.candlestick`、`ec.oc_price`
- 私有頻道：`ec.orders`、`ec.usertrades`、`ec.positions`、`ec.settlements`

公共頻道無需認證，私有頻道需要 Broker API Key 簽名。請參閱[WebSocket 協議](/zh-TW/event-contracts/websocket/protocol)、[公共頻道](/zh-TW/event-contracts/websocket/public-channels)和[私有頻道](/zh-TW/event-contracts/websocket/private-channels)。
