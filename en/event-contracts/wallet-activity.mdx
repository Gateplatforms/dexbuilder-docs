<Note>
  The private requests below use a Broker API Key. Send `KEY`, `Timestamp`, `SIGN`, and `sub_user_wallet_addr` with every request. Sign the exact external path, query string, and body. See [Broker API authentication](/en/event-contracts/api/broker-authentication).
</Note>

The Event Contracts API provides positions and trade records for the currently authenticated account. These are private endpoints and require authentication.

Production Base URL:

```text
https://api.dexbuilder.com
```

## List Positions

```bash cURL
curl -G "https://api.dexbuilder.com/api/v4/broker/event_contracts/positions" \
  -H "KEY: ${BROKER_API_KEY}" \
  -H "SIGN: ${SIGN}" \
  -H "Timestamp: ${TIMESTAMP}" \
  -H "sub_user_wallet_addr: ${WALLET}" \
  --data-urlencode "event_id=<event_id>" \
  --data-urlencode "condition_id=<condition_id>" \
  --data-urlencode "settlement_status=OPEN" \
  --data-urlencode "limit=20"
```

Common response fields include `position_id`, `event_id`, `token_id`, `outcome`, `size`, `available_size`, `locked_size`, `avg_open_price`, `position_value`, `settlement_status`, `won`, and `updated_at`.

## List Settled Positions

```bash cURL
curl -G "https://api.dexbuilder.com/api/v4/broker/event_contracts/positions/settled" \
  -H "KEY: ${BROKER_API_KEY}" \
  -H "SIGN: ${SIGN}" \
  -H "Timestamp: ${TIMESTAMP}" \
  -H "sub_user_wallet_addr: ${WALLET}"
```

This endpoint returns settled Event Contracts positions.

## List User Trades

```bash cURL
curl -G "https://api.dexbuilder.com/api/v4/broker/event_contracts/usertrades" \
  -H "KEY: ${BROKER_API_KEY}" \
  -H "SIGN: ${SIGN}" \
  -H "Timestamp: ${TIMESTAMP}" \
  -H "sub_user_wallet_addr: ${WALLET}" \
  --data-urlencode "condition_id=<condition_id>" \
  --data-urlencode "token_id=<token_id>" \
  --data-urlencode "limit=20"
```

User trade records typically include `trade_id`, `order_id`, `condition_id`, `token_id`, `price`, `size`, `side`, `role`, and `fee_rate`.

<Note>
Account endpoints query data for the currently authenticated user. They should not be interpreted as public on-chain query endpoints for arbitrary wallet addresses.
</Note>
