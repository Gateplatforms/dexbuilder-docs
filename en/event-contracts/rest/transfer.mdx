<Note>
  This endpoint is for Broker integration. Send a Broker API Key, `Timestamp`, `SIGN`, and `sub_user_wallet_addr`. The gateway verifies that the wallet belongs to the Broker. Sign the external `/api/v4/broker/...` path. See [Broker API authentication](/en/event-contracts/api/broker-authentication).
</Note>

Transfers USDT between a supported account and the product account.

**Base URL:** `https://api.dexbuilder.com`

## Request

```bash
curl -X POST "https://api.dexbuilder.com/api/v4/broker/event_contracts/transfer" \
  -H "KEY: ${BROKER_API_KEY}" \
  -H "SIGN: ${SIGN}" \
  -H "Timestamp: ${TIMESTAMP}" \
  -H "sub_user_wallet_addr: ${WALLET}" \
  -H "Content-Type: application/json" \
  -d '<request-body>'
```

The request body specifies the transfer direction and amount. Review the OpenAPI schema for required fields.

The field tables below define the documented parameters, types, and request-body fields. Timestamps are Unix timestamps unless the field description states otherwise.

## Response

Returns the transfer request status and identifiers. Verify the resulting balance and fund-flow record.

A successful response uses HTTP 200. Invalid parameters or request bodies return HTTP 400. Private endpoints can return HTTP 401 when authentication fails, and temporary upstream failures can return HTTP 503. The error response contains a machine-readable label and message.

For order, position, claim, transfer, and account operations, treat the response as the current server result and query the resource again when the operation is asynchronous.

## Endpoint fields

**Request path:** `POST /api/v4/broker/event_contracts/transfer`

### Request parameters

| Field | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `KEY` | header | string | Yes | Broker API Key |
| `Timestamp` | header | string | Yes | Unix time in seconds; within 60 seconds of gateway time |
| `SIGN` | header | string | Yes | Hex HMAC-SHA512 signature over the external request path, query string, and body |
| `sub_user_wallet_addr` | header | string | Yes | End-user wallet address; the gateway verifies its binding to this Broker |

### JSON request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `from_account` | string | Yes | spot / sub_spot / event_contract |
| `to_account` | string | Yes | spot / sub_spot / event_contract |
| `currency` | string | Yes | USDT |
| `amount` | string | Yes |  |
| `client_oid` | string | Yes |  |
