Submits an order.

**Base URL:** `https://api.dexbuilder.com`

**Authentication:** Use a Broker API Key and sign this request with `Timestamp` and `SIGN`. Pass a wallet address that belongs to your Broker in `sub_user_wallet_addr`. Calculate the signature using the external Broker path. See [Broker API Key and signing](/en/api-reference/common/broker-authentication) and [Access on behalf of a user](/en/api-reference/common/sub-user-wallet).

## Request

```bash
curl -X POST "https://api.dexbuilder.com/api/v4/broker/event_contracts/orders" \
  -H "KEY: ${BROKER_API_KEY}" \
  -H "SIGN: ${SIGN}" \
  -H "Timestamp: ${TIMESTAMP}" \
  -H "sub_user_wallet_addr: ${USER_WALLET}" \
  -H "Content-Type: application/json" \
  -d '<request-body>'
```

The request body contains only the public token, side, price/size or total cost, order type/mode, and optional client order and expiry fields shown in the OpenAPI definition.

The OpenAPI panel below is the source of truth for required parameters, types, enum values, and request-body fields. Timestamps are Unix timestamps unless the field description states otherwise.

## Response

Returns an acceptance object containing the order identifier and processing status. Query the order or subscribe to the private order channel for subsequent state changes.

A successful response uses HTTP 200. Invalid parameters or request bodies return HTTP 400. Private endpoints can return HTTP 401 when authentication fails, and temporary upstream failures can return HTTP 503. The error response contains a machine-readable label and message.

For order, position, claim, transfer, and account operations, treat the response as the current server result and query the resource again when the operation is asynchronous.
