This page shows how to build market activity views with the DexBuilder Event Contracts API. The examples use the production API:

```text
https://api.dexbuilder.com
```

Public market-data endpoints do not require authentication. Before querying activity, use [Discover Markets](./discover-markets) to obtain a `market_id`, `event_id`, `condition_id`, and `token_id`.

```bash
BASE_URL="https://api.dexbuilder.com"
MARKET_ID="<market_id>"
TOKEN_ID="<token_id>"
```

## Recent Trades

Use the market trades endpoint to inspect matched trades for a market. The response is an array; `price` and `size` are returned as strings.

```bash API
curl -G "$BASE_URL/api/v4/event_contracts/markets/$MARKET_ID/trades" \
  --data-urlencode "limit=100"
```

<Accordion title="Example Response">
  ```json
  [
    {
      "id": "trade-123",
      "market_id": "ge_market-1",
      "condition_id": "ge_condition-1",
      "token_id": "ge_token-yes",
      "outcome": "Yes",
      "side": "BUY",
      "price": "0.4500",
      "size": "10.0000",
      "created_at": 1720000000123
    }
  ]
  ```
</Accordion>

Use the `cursor` query parameter returned by the API when requesting the next page.

## Token Price and Ticker

Use the latest-price endpoint for the current price on one side of a market:

```bash API
curl "$BASE_URL/api/v4/event_contracts/tokens/$TOKEN_ID/price"
```

Use the ticker endpoint when you need the best bid, best ask, and last traded price:

```bash API
curl "$BASE_URL/api/v4/event_contracts/tokens/$TOKEN_ID/ticker"
```

<Accordion title="Ticker Response">
  ```json
  {
    "token_id": "ge_token-yes",
    "best_bid": "0.4400",
    "best_ask": "0.4600",
    "last_price": "0.4500",
    "timestamp": 1720000000123
  }
  ```
</Accordion>

## Price History

Use price history to plot historical token prices. `from` and `to` are Unix timestamps in milliseconds.

```bash API
curl -G "$BASE_URL/api/v4/event_contracts/tokens/$TOKEN_ID/price_history" \
  --data-urlencode "interval=1h" \
  --data-urlencode "from=1720000000000" \
  --data-urlencode "to=1720036000000"
```

<Accordion title="Example Response">
  ```json
  {
    "history": [
      {
        "p": "0.4500",
        "t": 1720000000000
      },
      {
        "p": "0.4700",
        "t": 1720003600000
      }
    ]
  }
  ```
</Accordion>

## Candlesticks

Use the candlestick endpoint for time-bucketed price and volume data for a supported currency.

```bash API
curl -G "$BASE_URL/api/v4/event_contracts/tokens/BTC/candlesticks" \
  --data-urlencode "interval=1m" \
  --data-urlencode "limit=100"
```

The available intervals and returned fields are defined by the OpenAPI reference. Treat numeric values as strings where specified to avoid precision loss.

## Market and Event Aggregation

Use the Events and Markets endpoints to build market lists and aggregate application-level metrics:

- `GET /api/v4/event_contracts/events` lists events and supports cursor pagination.
- `GET /api/v4/event_contracts/markets` lists markets and supports filters such as `event_id`, `slug`, `condition_id`, and `tag_slug`.
- `GET /api/v4/event_contracts/markets/{market_id}/trades` provides the trade-level data used for volume and activity calculations.

DexBuilder does not expose Polymarket `data-api` endpoints such as `/oi`, `/holders`, or `/live-volume`. Do not use those external URLs as part of a DexBuilder integration.

## Real-Time Analytics

For streaming dashboards, subscribe to the Event Contracts WebSocket and combine updates with REST snapshots:

```text
wss://broker.dexbuilder.com/ws/dex-builder/event-contracts
```

Public channels include `ec.trades`, `ec.depth`, `ec.bbo`, `ec.status`, `ec.cpi`, `ec.candlestick`, and `ec.oc_price`. See [Real-Time Data](./realtime-data) and [Public Channels](./websocket/public-channels) for subscription payloads and response envelopes.
