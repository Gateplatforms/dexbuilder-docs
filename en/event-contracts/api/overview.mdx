Event Contracts API provides REST API for market discovery, market data, orders, positions, account data, and claims, plus WebSocket for real-time updates.

## Base URL

```text
https://api.dexbuilder.com
```

## REST routes and identity

| Type | Path prefix |
| --- | --- |
| Public market-data path | `/api/v4/event_contracts` |
| Broker user-operation path | `/api/v4/broker/event_contracts` |

Public market data stays on its existing path without a Broker Key. Private order, position, account, and settlement endpoints use the Broker path. Send a Broker API Key, signature, and `sub_user_wallet_addr`; the gateway verifies that the wallet belongs to the Broker. See [Broker API authentication](/en/event-contracts/api/broker-authentication).
