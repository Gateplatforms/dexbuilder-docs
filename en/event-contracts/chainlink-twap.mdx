DexBuilder exposes configured reference-price updates through the Event Contracts WebSocket Broker. This page describes the public CPI channel used for intervals backed by Chainlink TWAP.

## Connection

```text
wss://broker.dexbuilder.com/ws/dex-builder/event-contracts
```

## Subscribe to a TWAP interval

Use the `ec.cpi` channel on the Event Contracts connection.

```json
{
  "t": 1720000000123,
  "id": "cpi-1",
  "op": "subscribe",
  "ch": "ec.cpi",
  "payload": {
    "items": [
      {
        "symbol": "btcusdt",
        "interval": "chainlink_twap_60s"
      }
    ]
  }
}
```

The configured deployment may expose the same source through supported interval aliases such as `5m`, `15m`, and `4h`. Confirm the interval contract with the current environment configuration.

## Response

```json
{
  "t": 1720000000124,
  "trace_id": "trace-1",
  "type": "update",
  "ch": "ec.cpi",
  "err": null,
  "result": {
    "symbol": "btcusdt",
    "interval": "chainlink_twap_60s",
    "price": "100000.10",
    "price_timestamp": "1720000000123",
    "ts": 1720000000123
  }
}
```

CPI is a public channel and does not require authentication. The server may reject intervals that are not configured for the deployment. Use `op: "unsubscribe"` with the same channel and payload to stop updates.

For the full envelope and reconnect behavior, see [WebSocket Protocol](./websocket/protocol), [Public Channels](./websocket/public-channels), and [Real-Time Data](./realtime-data).
