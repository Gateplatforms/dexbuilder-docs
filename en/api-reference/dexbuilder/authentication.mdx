---
title: "DexBuilder Platform API authentication"
description: "Use a Broker API Key and pass user wallet addresses on DexBuilder Platform endpoints."
---

Call DexBuilder Platform API endpoints at https://api.dexbuilder.com using the /api/v4/dexbuilder path prefix. Every endpoint requires KEY, Timestamp, and SIGN headers. See [Broker API Key and signing](/en/api-reference/common/broker-authentication).

Your Broker API Key needs the dex_builder product permission. Read operations require read or read-write access; submission operations require read-write access. An end user's personal API Key cannot replace a Broker API Key.

## User wallet

Asset-configuration endpoints do not require `sub_user_wallet_addr`. User, deposit, and withdrawal endpoints require the target user's wallet address in this header. The gateway verifies that the wallet belongs to your Broker. See [Access on behalf of a user](/en/api-reference/common/sub-user-wallet) for the full list.

Deposit and withdrawal submission endpoints also require Idempotency-Key. Other headers are specified on their endpoint pages.

## Example request

~~~bash
curl -i --request GET "https://api.dexbuilder.com/api/v4/dexbuilder/user/info" \
  --header "KEY: <BROKER_API_KEY>" \
  --header "SIGN: <SIGN>" \
  --header "Timestamp: <UNIX_SECONDS>" \
  --header "sub_user_wallet_addr: <USER_WALLET>" \
  --header "Accept: application/json"
~~~

Generate SIGN for the exact external path, method, query string, body, and timestamp that you send.
