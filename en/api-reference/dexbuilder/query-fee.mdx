Get the fixed deposit and withdrawal fees configured by network.

<Note>
  Use a Broker API Key. This endpoint reads Broker configuration and does not require X-User-Wallet-Address. See [Broker API Key and signing](/en/api-reference/common/broker-authentication).
</Note>

## Usage notes

- `network` identifies the network. `deposit_fee` and `withdraw_fee` are fixed amounts in USDT, not percentage rates. Pass the required `x-perp-device-type` header.
