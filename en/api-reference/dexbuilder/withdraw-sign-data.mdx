Get the data a user must sign to request a withdrawal.

<Note>
  Use a Broker API Key and pass the target user's wallet in X-User-Wallet-Address. The gateway checks that the wallet belongs to your Broker. See [Broker API Key and signing](/en/api-reference/common/broker-authentication).
</Note>

## Usage notes

- `address` is the user's bound signing wallet and the withdrawal destination. `to_address` is optional; if provided, it must equal `address`. This platform API does not support third-party withdrawal destinations.
- For EVM, response `data` is hex-encoded EIP-712 TypedData for wallet signing, not onchain transaction data. Do not broadcast it to `contract_address`.
- `timestamp` is a Unix timestamp in milliseconds. After signing, pass the signature components and the unchanged `timestamp` to [Submit a withdrawal](/en/api-reference/dexbuilder/withdraw-submit).
