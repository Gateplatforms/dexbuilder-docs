List the deposit and withdrawal networks available for an asset.

<Note>
  Use a Broker API Key. This endpoint reads Broker configuration and does not require sub_user_wallet_addr. See [Broker API Key and signing](/en/api-reference/common/broker-authentication).
</Note>

## Usage notes

- The current configuration primarily provides USDT on Ethereum.
- min_deposit and min_withdraw use display token units, not the chain's smallest unit.
