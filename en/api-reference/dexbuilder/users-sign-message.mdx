Get the wallet signing message and timestamp needed to [register a user and bind Perp](/en/api-reference/dexbuilder/users-register).

Call from your project server with a Broker API Key that has dex_builder read or read-write permission. Identify the wallet with the chain and address query parameters. See [Broker API Key and signing](/en/api-reference/common/broker-authentication).

## Sign the message

1. Pass chain and address, such as solana and the corresponding wallet address.
2. Preserve the returned message and timestamp. Use the wallet to sign the complete original message.
3. Submit the wallet signature as sign in the registration request and reuse the timestamp returned with this message.

The SIGN header authenticates the Broker's API v4 request. The sign body field contains the signature generated by the end-user wallet.

## Example request

This Python example reads Broker credentials and wallet details from server-side environment variables, signs the request, and sends the same request immediately.

```python
import hashlib
import hmac
import json
import os
import time
from urllib.parse import urlencode, unquote
from urllib.request import Request, urlopen

path = "/api/v4/dexbuilder/users/sign-message"
query = urlencode({
    "chain": os.environ["USER_WALLET_CHAIN"],
    "address": os.environ["USER_WALLET_ADDRESS"],
})
timestamp = str(int(time.time()))
signing_text = "\n".join([
    "GET", path, unquote(query), hashlib.sha512(b"").hexdigest(), timestamp,
])
signature = hmac.new(
    os.environ["BROKER_API_SECRET"].encode(),
    signing_text.encode(),
    hashlib.sha512,
).hexdigest()
request = Request(
    "https://api.dexbuilder.com" + path + "?" + query,
    headers={
        "KEY": os.environ["BROKER_API_KEY"],
        "Timestamp": timestamp,
        "SIGN": signature,
    },
)
with urlopen(request, timeout=15) as response:
    print(json.dumps(json.load(response), ensure_ascii=False, indent=2))
```
