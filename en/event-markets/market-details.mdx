Public Market lookups by ID and slug use different response models. ID lookups return a string `title` with `start_time` and `end_time`; slug lookups may include a multilingual `question` and trading-limit fields. Neither endpoint requires authentication.

Production Base URL:

```text
https://api.dexbuilder.com
```

## Query a Market

By Market ID:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/markets/<market_id>"
```

By slug:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/markets/slug/<market_slug>"
```

## Response by Market ID

This example is for `GET /api/v4/prediction/markets/{market_id}`. Use `outcomes[].token_id` to query prices and order books for that Token.

```json Example
{
  "market_id": "market-123",
  "event_id": "event-123",
  "slug": "example-market",
  "title": "Will the outcome occur?",
  "condition_id": "0xabc...",
  "status": "active",
  "closed": false,
  "accepting_orders": true,
  "enable_order_book": true,
  "start_time": 1782666000,
  "end_time": 1782752400,
  "outcomes": [
    { "outcome": "Yes", "token_id": "token-yes", "clob_token_id": "token-yes", "price": "0.50" },
    { "outcome": "No", "token_id": "token-no", "clob_token_id": "token-no", "price": "0.50" }
  ]
}
```

## Field reference

| Field | Description |
| --- | --- |
| `market_id`, `event_id` | Market ID and parent Event ID |
| `title` | Market title as a string |
| `condition_id` | Settlement Condition ID |
| `outcomes` | Each item contains string `outcome`, `token_id`, `clob_token_id`, and `price` |
| `status`, `closed` | Market state |
| `accepting_orders`, `enable_order_book` | Trading and order-book availability |
| `best_bid`, `best_ask`, `last_trade_price` | Order-book and latest-trade summary |
| `start_time`, `end_time` | Unix-second timestamps |

## Response by slug

`GET /api/v4/prediction/markets/slug/{slug}` uses a separate MarketDetail model. It may include a multilingual `question`, `min_order_size`, `tick_size`, `neg_risk`, and `resolved_at`. Follow the [Get Market by Slug](/en/event-markets/rest/query-market-by-slug) API Reference for its fields and types; do not mix it with the ID lookup response.

## Using Outcome Tokens

After obtaining a Token ID from `outcomes[].token_id`, you can call the price, Ticker, and order-book endpoints:

```bash cURL
TOKEN_ID="<token_id>"

curl "https://api.dexbuilder.com/api/v4/prediction/tokens/$TOKEN_ID/order_book?depth=20"
curl "https://api.dexbuilder.com/api/v4/prediction/tokens/$TOKEN_ID/price"
curl "https://api.dexbuilder.com/api/v4/prediction/tokens/$TOKEN_ID/ticker"
```

The API returns Token IDs directly in the `outcomes` array, so no additional parsing of JSON-string Token lists is required.

## Query the Parent Event

Use the returned `event_id` to query the parent Event:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/events/<event_id>"
```

Public Market data does not require authentication. Private order, position, and account endpoints do require authentication.
