<Note>
  This endpoint is for Broker integration. Send a Broker API Key, `Timestamp`, `SIGN`, and `sub_user_wallet_addr`. The gateway verifies that the wallet belongs to the Broker. Sign the external `/api/v4/broker/...` path. See [Broker API authentication](/en/event-markets/api/broker-authentication).
</Note>

Returns one authenticated position.

**Base URL:** `https://api.dexbuilder.com`

## Request

```bash
curl -G "https://api.dexbuilder.com/api/v4/broker/prediction/positions/{position_id}" \
  -H "KEY: ${BROKER_API_KEY}" \
  -H "SIGN: ${SIGN}" \
  -H "Timestamp: ${TIMESTAMP}" \
  -H "sub_user_wallet_addr: ${WALLET}"
```

`position_id` identifies the position.

The field tables below define the documented parameters, types, and request-body fields. Timestamps are Unix timestamps unless the field description states otherwise.

## Response

Returns the position identifiers, token and outcome, quantity, average price, settlement state, available quantity, locked quantity, claimable amount, and update timestamp. Mark-price fields are not part of the public documentation.

A successful response uses HTTP 200. Invalid parameters or request bodies return HTTP 400. Private endpoints can return HTTP 401 when authentication fails, and temporary upstream failures can return HTTP 503. The error response contains a machine-readable label and message.

For order, position, claim, transfer, and account operations, treat the response as the current server result and query the resource again when the operation is asynchronous.
