Prediction Markets API provides REST API for market discovery, market data, orders, positions, account data, and claims, plus WebSocket for real-time updates.

## Base URL

```text
https://api.dexbuilder.com
```

Public market-data REST endpoints use `/api/v4/prediction` and do not require authentication. Private order, position, account, and claim endpoints use `/api/v4/broker/prediction`. Call private endpoints with a Broker API Key and pass the target user's wallet address in `sub_user_wallet_addr`. See [Broker API Key and signing](/api-reference/common/broker-authentication) and [Access on behalf of a user](/api-reference/common/sub-user-wallet). Private WebSocket subscriptions use the separate [Broker WebSocket authentication](/en/event-markets/websocket/authentication) flow.
