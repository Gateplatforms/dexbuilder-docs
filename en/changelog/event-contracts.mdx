<Update label="2026-11-10" description="Crypto candlesticks">
  ## Crypto candlesticks

  Event Contracts now provides a public OHLCV candlestick endpoint at `GET /api/v4/event_contracts/crypto/candlesticks`. Use the currency code `symbol` for new integrations; `tag_id` remains temporarily supported. Provide exactly one of these parameters. Time boundaries and `history[].t` use Unix seconds. `interval=all` does not guarantee the full price history. See [Get Crypto Candlesticks](/en/event-contracts/rest/query-candlesticks) for the request and response contract.
</Update>

<Update label="2026-11-10" description="Broker API support">
  ## Event Contracts changelog

  Event Contracts supports Broker API Keys for private REST endpoints. A Broker can access these endpoints on behalf of its users and specify the user's wallet with `X-User-Wallet-Address`. Public market data remains available without authentication.

  See [Broker API Key and signing](/en/api-reference/common/broker-authentication) and the [Event Contracts API overview](/en/event-contracts/api/overview) for integration details.
</Update>
