  ## Event Contracts changelog

  Event Contracts supports Broker API Keys for private REST endpoints. A Broker can access these endpoints on behalf of its users and specify the user's wallet with `X-User-Wallet-Address`. Public market data remains available without authentication.

  See [Broker API Key and signing](/en/api-reference/common/broker-authentication) and the [Event Contracts API overview](/en/event-contracts/api/overview) for integration details.
</Update>
