  ## DexBuilder Platform API changelog

  The DexBuilder Platform API provides asset configuration, user queries, deposit, and withdrawal capabilities for Brokers. Use a Broker API Key to call the platform API. When acting for an end user, specify their wallet with `X-User-Wallet-Address`.

  See [Broker API Key and signing](/en/api-reference/common/broker-authentication), the [Platform API overview](/en/api-reference/dexbuilder/overview), and [Platform API authentication](/en/api-reference/dexbuilder/authentication) for integration details.
</Update>
