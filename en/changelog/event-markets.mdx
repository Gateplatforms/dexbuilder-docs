<Update label="2026-11-10" description="Crypto candlesticks">
  ## Crypto candlesticks

  Prediction now provides a public OHLCV candlestick endpoint at `GET /api/v4/prediction/crypto/candlesticks`. Use the currency code `symbol` for new integrations; `tag_id` remains temporarily supported. Provide exactly one of these parameters. Time boundaries and `history[].t` use Unix seconds. `interval=all` does not guarantee the full price history. See [Get Crypto Candlesticks](/en/event-markets/rest/query-candlesticks) for the request and response contract.
</Update>

<Update label="2026-11-10" description="Broker API support">
  ## Prediction changelog

  Prediction supports Broker API Keys for private REST endpoints. A Broker can access these endpoints on behalf of its users and specify the user's wallet with `X-User-Wallet-Address`. Public market data remains available without authentication.

  See [Broker API Key and signing](/en/api-reference/common/broker-authentication) and the [Prediction API overview](/en/event-markets/api/overview) for integration details.
</Update>
