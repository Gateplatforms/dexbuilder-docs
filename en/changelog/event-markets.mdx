<Update label="2026-11-10" description="Candlestick API update">
  ## Crypto candlestick API updated

  The Prediction documentation now recommends `GET /api/v4/prediction/crypto/candlesticks` for public crypto candlesticks. Compared with the previously documented `GET /api/v4/prediction/tokens/{currency}/candlesticks`, the new endpoint uses the `symbol` query parameter and requires `interval`; use `start_ts/end_ts` for the time range. A successful response is an object with `symbol`, `interval`, and `history`, rather than a candlestick array. `tag_id` remains temporarily supported and must not be sent with `symbol`. The previous endpoint remains available for existing clients. See [Get Crypto Candlesticks](/en/event-markets/rest/query-candlesticks) for the new contract.
</Update>

<Update label="2026-11-10" description="Broker API support">
  ## Prediction changelog

  Prediction supports Broker API Keys for private REST endpoints. A Broker can access these endpoints on behalf of its users and specify the user's wallet with `X-User-Wallet-Address`. Public market data remains available without authentication.

  See [Broker API Key and signing](/en/api-reference/common/broker-authentication) and the [Prediction API overview](/en/event-markets/api/overview) for integration details.
</Update>
