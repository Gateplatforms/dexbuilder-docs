本页介绍如何使用 DexBuilder Prediction API 构建市场活动分析。以下示例使用生产环境 API：

```text
https://api.dexbuilder.com
```

公开行情接口不需要认证。开始查询前，可先通过「发现市场」获取 `market_id`、`event_id`、`condition_id` 和 `token_id`。

```bash
BASE_URL="https://api.dexbuilder.com"
MARKET_ID="<market_id>"
TOKEN_ID="<token_id>"
```

## 最近成交

使用市场成交接口查看指定市场的撮合成交。返回值是数组，`price` 和 `size` 按字符串返回。

```bash API
curl -G "$BASE_URL/api/v4/prediction/markets/$MARKET_ID/trades" \
  --data-urlencode "limit=100"
```

<Accordion title="响应示例">
  ```json
  [
    {
      "id": "trade-123",
      "market_id": "ge_market-1",
      "condition_id": "ge_condition-1",
      "token_id": "ge_token-yes",
      "outcome": "Yes",
      "side": "BUY",
      "price": "0.4500",
      "size": "10.0000",
      "created_at": 1720000000123
    }
  ]
  ```
</Accordion>

请求下一页时，使用接口返回的 `cursor` 查询参数。

## Token 价格与 Ticker

使用最新价格接口获取市场某一方的当前价格：

```bash API
curl "$BASE_URL/api/v4/prediction/tokens/$TOKEN_ID/price"
```

需要最佳买价、最佳卖价和最近成交价时，使用 Ticker 接口：

```bash API
curl "$BASE_URL/api/v4/prediction/tokens/$TOKEN_ID/ticker"
```

<Accordion title="Ticker 响应">
  ```json
  {
    "token_id": "ge_token-yes",
    "best_bid": "0.4400",
    "best_ask": "0.4600",
    "last_price": "0.4500",
    "timestamp": 1720000000123
  }
  ```
</Accordion>

## 价格历史

使用价格历史接口绘制 Token 历史价格。 `from` 和 `to` 是毫秒级 Unix 时间戳。

```bash API
curl -G "$BASE_URL/api/v4/prediction/tokens/$TOKEN_ID/price_history" \
  --data-urlencode "interval=1h" \
  --data-urlencode "from=1720000000000" \
  --data-urlencode "to=1720036000000"
```

<Accordion title="响应示例">
  ```json
  {
    "history": [
      {
        "p": "0.4500",
        "t": 1720000000000
      },
      {
        "p": "0.4700",
        "t": 1720003600000
      }
    ]
  }
  ```
</Accordion>

## K 线

使用 K 线接口获取受支持币种的分时价格和成交量数据。

```bash API
curl -G "$BASE_URL/api/v4/prediction/tokens/BTC/candlesticks" \
  --data-urlencode "interval=1m" \
  --data-urlencode "limit=100"
```

可用周期和返回字段以 OpenAPI 参考为准。对于接口声明为字符串的数值字段，应按字符串处理，避免精度损失。

## 市场与事件聚合

可使用 Event 和 Market 接口构建市场列表，并在应用层计算分析指标：

- `GET /api/v4/prediction/events` 获取事件列表，支持 cursor 分页。
- `GET /api/v4/prediction/markets` 获取市场列表，支持按 `event_id`、`slug`、`condition_id` 和 `tag_slug` 等条件筛选。
- `GET /api/v4/prediction/markets/{market_id}/trades` 提供用于计算成交量和活动指标的成交明细。

DexBuilder 不提供 Polymarket `data-api` 中的 `/oi`、`/holders` 或 `/live-volume` 接口。DexBuilder 集成中不要使用这些外部地址。

## 实时分析

实时看板可以订阅 Prediction Markets WebSocket，并结合 REST 快照：

```text
wss://broker.dexbuilder.com/ws/dex-builder/prediction
```

公开频道包括 `pred.trades`、`pred.depth`、`pred.bbo`、`pred.status`、`pred.cpi`、`pred.candlestick` 和 `pred.oc_price`。订阅参数和返回消息格式请参阅「实时数据」与「公共频道」。
