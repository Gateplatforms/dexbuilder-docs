根据 Market ID 或 slug 查询公开市场数据时，请区分两种响应模型。按 ID 查询返回 `title` 字符串及 `start_time`、`end_time`；按 slug 查询可返回多语言 `question` 和交易限制等扩展字段。两种接口均无需认证。

生产环境 Base URL：

```text
https://api.dexbuilder.com
```

## 查询 Market

根据 Market ID：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/markets/<market_id>"
```

根据 slug：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/markets/slug/<market_slug>"
```

## 按 ID 查询的响应

以下示例对应 `GET /api/v4/prediction/markets/{market_id}`。`outcomes[].token_id` 可直接用于对应 Token 的价格和订单簿接口。

```json Example
{
  "market_id": "market-123",
  "event_id": "event-123",
  "slug": "example-market",
  "title": "Will the outcome occur?",
  "condition_id": "0xabc...",
  "status": "active",
  "closed": false,
  "accepting_orders": true,
  "enable_order_book": true,
  "start_time": 1782666000,
  "end_time": 1782752400,
  "outcomes": [
    { "outcome": "Yes", "token_id": "token-yes", "clob_token_id": "token-yes", "price": "0.50" },
    { "outcome": "No", "token_id": "token-no", "clob_token_id": "token-no", "price": "0.50" }
  ]
}
```

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `market_id`、`event_id` | Market 与所属 Event 的 ID |
| `title` | 市场标题，字符串 |
| `condition_id` | 结算 Condition ID |
| `outcomes` | 每项包含字符串 `outcome`、`token_id`、`clob_token_id` 和 `price` |
| `status`、`closed` | 市场状态 |
| `accepting_orders`、`enable_order_book` | 交易与订单簿开关 |
| `best_bid`、`best_ask`、`last_trade_price` | 盘口与最近成交摘要 |
| `start_time`、`end_time` | Unix 秒级时间戳 |

## 按 slug 查询的响应

`GET /api/v4/prediction/markets/slug/{slug}` 使用另一种 MarketDetail 模型，可包含多语言 `question`、`min_order_size`、`tick_size`、`neg_risk`、`resolved_at` 等字段。其字段及类型以[按 Slug 查询市场](/zh/event-markets/rest/query-market-by-slug)为准，不应与按 ID 查询的响应混用。

## 使用 Outcome Token

从 `outcomes[].token_id` 获取 Token ID 后，可以继续调用价格、Ticker 和订单簿接口：

```bash cURL
TOKEN_ID="<token_id>"

curl "https://api.dexbuilder.com/api/v4/prediction/tokens/$TOKEN_ID/order_book?depth=20"
curl "https://api.dexbuilder.com/api/v4/prediction/tokens/$TOKEN_ID/price"
curl "https://api.dexbuilder.com/api/v4/prediction/tokens/$TOKEN_ID/ticker"
```

API 已直接在 `outcomes` 数组中返回 Token ID，无需额外解析 JSON 字符串形式的 Token 列表。

## 查询所属 Event

使用响应中的 `event_id` 查询父级 Event：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/prediction/events/<event_id>"
```

Market 公开数据无需认证；下单、持仓、账户等私有接口需要认证。
