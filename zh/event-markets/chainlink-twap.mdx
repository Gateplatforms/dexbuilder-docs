DexBuilder 通过 Prediction Markets WebSocket Broker 的公开 CPI 频道提供配置的参考价格更新。本页介绍由 Chainlink TWAP 支持的周期如何通过 Broker 订阅。

## 连接地址

```text
wss://broker.dexbuilder.com/ws/dex-builder/prediction
```

Event Contracts 使用：

```text
wss://broker.dexbuilder.com/ws/dex-builder/event-contracts
```

## 订阅 TWAP 周期

Prediction Markets 使用 `pred.cpi` 频道；Event Contracts 使用 `ec.cpi` 频道。

```json
{
  "t": 1720000000123,
  "id": "cpi-1",
  "op": "subscribe",
  "ch": "pred.cpi",
  "payload": {
    "items": [
      {
        "symbol": "btcusdt",
        "interval": "chainlink_twap_60s"
      }
    ]
  }
}
```

部署配置可能通过 `5m`、`15m` 和 `4h` 等周期别名使用同一来源。具体可用周期以当前环境配置为准。

## 返回消息

```json
{
  "t": 1720000000124,
  "trace_id": "trace-1",
  "type": "update",
  "ch": "pred.cpi",
  "err": null,
  "result": {
    "symbol": "btcusdt",
    "interval": "chainlink_twap_60s",
    "price": "100000.10",
    "price_timestamp": "1720000000123",
    "ts": 1720000000123
  }
}
```

价格和时间戳按照消息协议分别以字符串或整数返回。不要根据返回消息推断数据源，数据源由周期配置决定。

## 订阅规则

- CPI 是公开频道，不需要认证；
- `symbol` 和 `interval` 必填；
- 未在部署中配置的周期可能会被服务端拒绝；
- 使用相同频道和 payload 搭配 `op: "unsubscribe"` 取消订阅。

完整消息结构和重连行为请参阅「WebSocket 协议」「公共频道」和「实时数据」。
