## 标签

```text
GET /api/v4/prediction/tags
```

公开接口。支持 `limit` 和 `cursor`。

返回 `items` 与 `next_cursor`，每个标签通常包含：

- `tag_id`
- `slug`
- `label` 多语言对象

## 加密货币 K 线

```text
GET /api/v4/prediction/crypto/candlesticks
```

使用必填的加密货币标签 ID `tag_id` 和展示档位 `interval` 查询；可选的 `start_ts`、`end_ts` 使用 Unix 秒。响应的 `history` 包含 K 线数组，每根 K 线的 `t` 也使用 Unix 秒。参见[查询加密货币 K 线](/zh/event-markets/rest/query-candlesticks)。

## 服务器时间

```text
GET /api/v4/prediction/time
```

返回字段 `server_time`，单位为 Unix 毫秒。
