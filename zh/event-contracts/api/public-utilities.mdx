## 标签

```text
GET /api/v4/event_contracts/tags
```

公开接口，支持 `limit` 和 `cursor`。

## 加密货币 K 线

```text
GET /api/v4/event_contracts/crypto/candlesticks
```

使用必填的加密货币标签 ID `tag_id` 和展示档位 `interval` 查询；可选的 `start_ts`、`end_ts` 使用 Unix 秒。响应的 `history` 包含 K 线数组，每根 K 线的 `t` 也使用 Unix 秒。参见[查询加密货币 K 线](/zh/event-contracts/rest/query-candlesticks)。

## 服务器时间

```text
GET /api/v4/event_contracts/time
```

返回 `server_time`，单位为 Unix 毫秒。
