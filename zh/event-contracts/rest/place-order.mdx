<Note>
  此接口仅供 Broker 使用。请求须携带 Broker API Key、`Timestamp`、`SIGN` 和 `sub_user_wallet_addr`。网关确认钱包属于当前 Broker 后转发。请按外部 `/api/v4/broker/...` 路径计算签名。详见[Broker API 认证与签名](/zh/event-contracts/api/broker-authentication).
</Note>

提交订单。

## 接口字段

**请求路径:** `POST /api/v4/broker/event_contracts/orders`

### 请求参数

| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `KEY` | header | string | 是 | Broker API Key |
| `Timestamp` | header | string | 是 | Unix 秒级时间戳，与网关时间差不超过 60 秒 |
| `SIGN` | header | string | 是 | 按实际外部请求路径、Query 和 Body 生成的 HMAC-SHA512 十六进制签名 |
| `sub_user_wallet_addr` | header | string | 是 | 目标终端用户的钱包地址；网关校验该钱包属于当前 Broker |

### JSON 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `token_id` | string | 是 |  |
| `side` | string | 是 | BUY / SELL |
| `price` | string | 否 |  |
| `size` | string | 否 |  |
| `total_cost` | string | 否 |  |
| `order_type` | string | 否 |  |
| `order_mode` | string | 否 |  |
| `client_order_id` | string | 否 |  |
| `post_only` | boolean | 否 |  |
| `sell_all` | boolean | 否 |  |
| `expire_time` | integer | 否 |  |

### 成功响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `client_order_id` | string |  |
| `created_at` | integer |  |
| `order_id` | string |  |
| `status` | string |  |

接口契约列出的响应状态：`200`, `400`, `401`, `503`。Broker 无权限或钱包绑定校验未通过时，网关还可能返回 `403`。

字段定义依据当前接口契约；实际错误信息以响应为准。
