<Note>
  此接口仅供 Broker 使用。请求须携带 Broker API Key、`Timestamp`、`SIGN` 和 `sub_user_wallet_addr`。网关确认钱包属于当前 Broker 后转发。请按外部 `/api/v4/broker/...` 路径计算签名。详见[Broker API 认证与签名](/zh/event-contracts/api/broker-authentication).
</Note>

查询持仓列表。

## 接口字段

**请求路径:** `GET /api/v4/broker/event_contracts/positions`

### 请求参数

| 字段 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `KEY` | header | string | 是 | Broker API Key |
| `Timestamp` | header | string | 是 | Unix 秒级时间戳，与网关时间差不超过 60 秒 |
| `SIGN` | header | string | 是 | 按实际外部请求路径、Query 和 Body 生成的 HMAC-SHA512 十六进制签名 |
| `sub_user_wallet_addr` | header | string | 是 | 目标终端用户的钱包地址；网关校验该钱包属于当前 Broker |
| `event_id` | query | string | 否 |  |
| `condition_id` | query | string | 否 |  |
| `settlement_status` | query | string | 否 |  |
| `cursor` | query | string | 否 |  |
| `limit` | query | integer | 否 |  |

### 成功响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `items` | PositionItem[] |  |
| `items[].available_size` | string |  |
| `items[].avg_open_price` | string |  |
| `items[].claimable_amount` | string |  |
| `items[].event_id` | string |  |
| `items[].locked_size` | string |  |
| `items[].outcome` | string |  |
| `items[].position_id` | string |  |
| `items[].position_value` | string |  |
| `items[].settlement_status` | string |  |
| `items[].size` | string |  |
| `items[].token_id` | string |  |
| `items[].updated_at` | integer |  |
| `items[].won` | boolean |  |
| `next_cursor` | string |  |

接口定义的响应状态：`200`, `400`, `401`, `503`。

字段定义依据当前接口契约；实际错误信息以响应为准。
