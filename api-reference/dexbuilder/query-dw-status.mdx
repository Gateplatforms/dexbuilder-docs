查询资产及网络的充值和提现开关。

<Note>
  使用 Broker API Key 调用。此接口查询 Broker 配置，无需提供 `X-User-Wallet-Address`。 认证规则见[Broker API Key 与签名](/api-reference/common/broker-authentication)。
</Note>

## 使用说明

- `network` 必填，用于指定查询的网络；`asset` 可选。未提供 `asset` 时，响应中的对应字段为空字符串。
