`GET /api/dexbuilder/dw_status`

查询指定资产与网络的充值/提现是否开启。

调用前请阅读[认证与 API Key](/api-reference/dexbuilder/authentication)。`X-Broker-ID` 对应接入的 Broker，按网关配置传递或由网关注入。

## 请求参数

| 参数 | 位置 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `asset` | query | 否 | string | ；示例：`USDT` |
| `network` | query | 否 | string | ；示例：`ethereum` |

## 响应

成功时返回统一结构：`code`、`message`、`data`、`trace_id`；具体 `data` 字段如下。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.asset` | string |  |
| `data.network` | string |  |
| `data.deposit_enabled` | boolean |  |
| `data.withdraw_enabled` | boolean |  |
