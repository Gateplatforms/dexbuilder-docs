---
title: "查询 Broker 用户列表"
description: "分页查询当前 Broker 下按用户标识去重的用户列表。"
openapi: "/openapi/dexbuilder.yaml GET /api/v4/dexbuilder/users"
---

按 `broker_uid` 去重，分页返回当前 Broker 下已绑定 Perp 子账号的用户。默认只返回激活用户。

需要项目方 Broker API Key 的 `dex_builder` 只读或读写权限，认证规则见[Broker API Key 与签名](/api-reference/common/broker-authentication)。

## 分页与返回字段

`page` 从 1 开始，默认 1。`page_size` 范围为 1 到 100，默认 20。可选 `include_suspended` 接受 `1`、`true`、`0`、`false`，传 `1` 或 `true` 时同时返回停用用户。`data` 包含 `items`、`page`、`page_size` 和 `total`，其中 `total` 为符合筛选条件的用户数。

列表条目包含 `broker_uid`、`primary_address`、`status`（`active` 或 `suspended`）和 Unix 毫秒时间戳 `created_at`。`user_id` 可能省略，EVM 主钱包地址以小写返回。

## 调用示例

```http
GET /api/v4/dexbuilder/users?page=1&page_size=1 HTTP/1.1
Host: api.dexbuilder.com
KEY: <BROKER_API_KEY>
Timestamp: <UNIX_SECONDS>
SIGN: <SIGN>
```

签名原文中的 Query 参数串为 `page=1&page_size=1`。按响应的 `total`、`page` 和 `page_size` 继续查询后续页面。
