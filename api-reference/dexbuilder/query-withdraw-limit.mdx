查询单笔及单日提现限额。

<Note>
  使用 Broker API Key 调用。此接口查询 Broker 配置，无需提供 `sub_user_wallet_addr`。 认证规则见[Broker API Key 与签名](/api-reference/common/broker-authentication)。
</Note>

## 使用说明

- `once` 与 `day` 为 USDT 计价的限额。可通过 `network` 查询指定网络的最小提现额 `min_withdraw`；未指定网络时不返回该字段。调用时须提供 `x-perp-device-type`，取值见[平台 API 认证](/api-reference/dexbuilder/authentication)。
