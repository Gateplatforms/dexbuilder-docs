`GET /api/v4/dexbuilder/fund_stats`

查询终端用户的资金统计。

此接口代终端用户操作。请求头必须提供 `sub_user_wallet_addr`；网关核验该钱包属于当前 Broker 后才会转发。详见[认证与 API Key](/api-reference/dexbuilder/authentication)。

## 请求参数

| 参数 | 位置 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `x-gate-device-type` | header | 是 | string | 设备类型，须为 Perp 支持的枚举值（如 web）；示例：`web` |
| `sub_user_wallet_addr` | header | 是 | string | 终端用户钱包地址；网关校验该钱包与当前 Broker 的绑定 |

## 响应

成功时返回统一结构：`code`、`message`、`data`、`trace_id`。`data` 包含以下字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.list` | array | 各链的资金统计列表 |
| `data.list[].chain` | string | 链标识 |
| `data.list[].deposit` | string | 累计充值，单位待确认 |
| `data.list[].withdraw` | string | 累计提现，单位待确认 |
