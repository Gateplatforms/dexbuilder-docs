`POST /api/dexbuilder/deposit/sign_data`

返回链上充值所需的 calldata 与 vault 合约地址；可能触发 Perp 账户绑定。

调用前请阅读[认证与 API Key](/api-reference/dexbuilder/authentication)。`X-Broker-ID` 对应接入的 Broker，按网关配置传递或由网关注入。

## 请求参数

| 参数 | 位置 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `x-gate-device-type` | header | 是 | string | 设备类型，须为 Perp 支持的枚举值（如 web）；示例：`web` |
| `X-User-Id` | header | 否 | string | 项目方映射的终端用户 ID（亦可使用 X-Gate-User-Id 或 query user_id） |
| `sub_user_wallet_addr` | header | 否 | string | 网关透传的终端钱包，用于反查 user_id |

## 请求体

`Content-Type: application/json`。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `address` | string | 是 |  |
| `chain` | string | 是 |  |
| `token_address` | string | 是 |  |
| `token_amount` | string | 是 |  |
| `token_symbol` | string | 是 |  |
| `native_fee` | integer | 否 |  |
| `lz_fee` | integer | 否 |  |

## 响应

成功时返回统一结构：`code`、`message`、`data`、`trace_id`；具体 `data` 字段如下。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.account_id` | string |  |
| `data.broker_hash` | string |  |
| `data.token_hash` | string |  |
| `data.token_amount` | string |  |
| `data.contract_address` | string |  |
| `data.data` | string |  |
