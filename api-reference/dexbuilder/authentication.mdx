title: "认证与 API Key"
description: "创建并使用 DexBuilder 项目方 API Key，按 Gate APIv4 规则签名请求。"
---

DexBuilder 平台 API 使用项目方 API Key。网关按 Gate APIv4 规则验证 `KEY`、`Timestamp` 和 `SIGN`；服务继续校验 Key 与 Broker 项目的绑定。终端用户标识与项目方 Key 是两类不同的身份信息。

## 获取和配置 API Key

1. 按项目接入流程确认 Broker ID、网关地址及项目方 API Key 的绑定关系。
2. 如需在 Gate 账户自行创建 APIv4 Key，可登录后进入「账户管理 → APIv4 Keys」，创建 Key 并按接入要求配置权限。创建后保存 `Key` 和 `Secret Key`；`Key` 用于请求头，`Secret Key` 只用于本地签名。具体入口和权限说明参见 [Gate APIv4 认证文档](https://www.gate.com/docs/developers/apiv4/zh_CN/#%E8%AE%A4%E8%AF%81)。
3. 建议限制调用服务器的 IP 白名单，并确认相应网关环境和权限已经开通。Key 的 Broker 绑定须按项目接入流程完成；仅创建普通 APIv4 Key 并不代表已完成 DexBuilder 项目绑定。

<Warning>
  不要将 Secret Key 放到前端、提交到代码仓库，或写入日志。若密钥泄露，请停用并重新生成。
</Warning>

## 请求头

| Header | 说明 |
| --- | --- |
| `KEY` | 与 Broker 绑定的项目方 API Key |
| `Timestamp` | 当前 Unix 秒级时间戳；与网关时间差不超过 60 秒 |
| `SIGN` | 使用 Secret Key 计算的 HMAC-SHA512 十六进制签名 |
| `X-Broker-ID` | 项目对应的 Broker ID；由网关或中间件注入时无需客户端重复填写，具体以接入配置为准 |
| `X-User-Id` | 用户级接口的终端用户 ID；也可按接入约定使用 `X-Gate-User-Id` 或 `user_id` 查询参数 |
| `sub_user_wallet_addr` | 终端用户钱包地址，可用于反查用户 ID；由网关透传时无需重复填写 |
| `x-gate-device-type` | 部分 Perp 转发接口必需，例如 `web`；以各接口参数表为准 |
| `Idempotency-Key` | 提交充值回执、提交提现时必需；同一次业务操作重试应保持一致 |

资产配置下的 `/assets`、`/networks`、`/dw_status`、`/fee`、`/withdraw_limit` 不需要 `sub_user_wallet_addr`，但仍需项目方 API Key 签名和 Broker 绑定。用户级接口须提供可解析的终端用户身份信息。具体参数以各接口页为准。

## 生成签名

将以下五段内容按顺序以换行符 `\n` 连接：

```text
HTTP 方法（大写）
请求路径（包含 /api/dexbuilder，不包含域名）
实际发送的 Query String；没有时为空字符串
实际发送的请求体原文的 SHA512 十六进制摘要；没有请求体时对空字符串计算
Timestamp 请求头的值
```

随后计算：

```text
SIGN = HexEncode(HMAC_SHA512(Secret Key, 上述签名原文))
```

例如查询支持资产时，方法为 `GET`，签名路径为 `/api/dexbuilder/assets`。无 Query String 和请求体时，对应两段分别为空字符串和空字符串的 SHA512 摘要。Query 参数的顺序与实际发送的请求一致；POST 请求体必须以实际发送的字节计算摘要。

<Note>
  Gate APIv4 文档中的 `/api/v4/...` 是其接口示例。DexBuilder 平台 API 的签名路径使用实际请求的 `/api/dexbuilder/...`。
</Note>

## 调用示例

以下 Python 示例调用资产列表接口。将网关地址、Key 和 Secret Key 作为服务端环境变量保存；若网关未注入 Broker ID，再设置 `DEXBUILDER_BROKER_ID`。

```python
import hashlib
import hmac
import os
import time
from urllib.request import Request, urlopen

base_url = os.environ["DEXBUILDER_API_BASE_URL"].rstrip("/")
key = os.environ["DEXBUILDER_API_KEY"]
secret = os.environ["DEXBUILDER_API_SECRET"]
path = "/api/dexbuilder/assets"
timestamp = str(int(time.time()))
body = b""
payload_hash = hashlib.sha512(body).hexdigest()
signature_string = "\n".join(["GET", path, "", payload_hash, timestamp])
signature = hmac.new(
    secret.encode("utf-8"), signature_string.encode("utf-8"), hashlib.sha512
).hexdigest()
headers = {"KEY": key, "Timestamp": timestamp, "SIGN": signature}
broker_id = os.getenv("DEXBUILDER_BROKER_ID")
if broker_id:
    headers["X-Broker-ID"] = broker_id
request = Request(base_url + path, headers=headers)
with urlopen(request) as response:
    print(response.read().decode("utf-8"))
```

完整的 Gate APIv4 签名规则见 [Gate APIv4 认证文档](https://www.gate.com/docs/developers/apiv4/zh_CN/#%E8%AE%A4%E8%AF%81)。
