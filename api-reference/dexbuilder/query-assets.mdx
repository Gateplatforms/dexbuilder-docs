title: "查询支持资产"
description: "返回当前 Broker 支持的充值和提现资产列表。"
---

`GET /api/v4/dexbuilder/assets`

返回当前 Broker 支持的充值和提现资产列表。

此接口查询 Broker 配置，无需钱包地址；仍须使用 Broker API Key 签名。详见[认证与 API Key](/api-reference/dexbuilder/authentication)。

## 响应

成功时返回统一结构：`code`、`message`、`data`、`trace_id`；具体 `data` 字段如下。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data[].asset` | string | 示例：`USDT` |
| `data[].name` | string | 示例：`Tether USD` |
