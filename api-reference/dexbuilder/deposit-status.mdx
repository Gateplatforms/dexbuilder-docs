`GET /api/dexbuilder/deposit/status`

查询充值状态

调用前请阅读[认证与 API Key](/api-reference/dexbuilder/authentication)。`X-Broker-ID` 对应接入的 Broker，按网关配置传递或由网关注入。

## 请求参数

| 参数 | 位置 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `tx_hash` | query | 是 | string | EVM 或 Solana 交易哈希 |

## 响应

成功时返回统一结构：`code`、`message`、`data`、`trace_id`；具体 `data` 字段如下。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.tx_hash` | string |  |
| `data.status` | integer | 0 未查询到；10 确认中；20 成功；30 失败 |
