`POST /api/dexbuilder/withdraw/submit`

提交已签名的提现请求；支持 Idempotency-Key 幂等。

调用前请阅读[认证与 API Key](/api-reference/dexbuilder/authentication)。`X-Broker-ID` 对应接入的 Broker，按网关配置传递或由网关注入。

## 请求参数

| 参数 | 位置 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `Idempotency-Key` | header | 是 | string |  |
| `x-gate-device-type` | header | 是 | string | 设备类型，须为 Perp 支持的枚举值（如 web）；示例：`web` |
| `X-User-Id` | header | 否 | string | 项目方映射的终端用户 ID（亦可使用 X-Gate-User-Id 或 query user_id） |
| `sub_user_wallet_addr` | header | 否 | string | 网关透传的终端钱包，用于反查 user_id |

## 请求体

`Content-Type: application/json`。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `broker_uid` | integer | 否 |  |
| `r` | string | 否 |  |
| `v` | integer | 否 |  |
| `s` | string | 否 |  |
| `chain` | string | 否 |  |
| `token_address` | string | 否 |  |
| `address` | string | 否 |  |
| `token_amount` | string | 否 |  |
| `to_address` | string | 否 |  |
| `timestamp` | integer | 否 |  |
| `token_symbol` | string | 否 |  |

## 响应

成功时返回统一结构：`code`、`message`、`data`、`trace_id`；具体 `data` 字段如下。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.event_id` | string |  |
| `data.success` | boolean |  |

<Note>
  提交接口要求 `Idempotency-Key`；对同一业务操作重试时复用相同的 Key。
</Note>
