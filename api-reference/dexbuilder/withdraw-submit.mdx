`POST /api/v4/dexbuilder/withdraw/submit`

提交已签名的提现请求；请求头必须携带 `Idempotency-Key`。

此接口代终端用户操作。请求头必须提供 `sub_user_wallet_addr`；网关核验该钱包属于当前 Broker 后才会转发。详见[认证与 API Key](/api-reference/dexbuilder/authentication)。

## 请求参数

| 参数 | 位置 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `Idempotency-Key` | header | 是 | string |  |
| `x-gate-device-type` | header | 是 | string | 设备类型，须为 Perp 支持的枚举值（如 web）；示例：`web` |
| `sub_user_wallet_addr` | header | 是 | string | 终端用户钱包地址；网关校验该钱包与当前 Broker 的绑定 |

## 请求体

`Content-Type: application/json`。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `r` | string | 否 |  |
| `v` | integer | 否 |  |
| `s` | string | 否 |  |
| `chain` | string | 否 |  |
| `token_address` | string | 否 |  |
| `address` | string | 否 |  |
| `token_amount` | string | 否 |  |
| `to_address` | string | 否 |  |
| `timestamp` | integer | 否 |  |
| `token_symbol` | string | 否 |  |

## 响应

成功时返回统一结构：`code`、`message`、`data`、`trace_id`；具体 `data` 字段如下。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.event_id` | string |  |
| `data.success` | boolean |  |

<Note>
  提交接口要求 `Idempotency-Key`；对同一业务操作重试时复用相同的 Key。
</Note>
