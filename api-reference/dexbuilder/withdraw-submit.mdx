提交已签名的提现请求。

<Note>
  使用 Broker API Key 调用，并在请求头提供 `sub_user_wallet_addr`。网关会校验钱包与 Broker 的归属关系。 认证规则见[Broker API Key 与签名](/api-reference/common/broker-authentication)。
</Note>

## 使用说明

- `r`、`v`、`s` 为用户对签名数据的签名分量；`timestamp` 必须与[获取提现签名数据](/api-reference/dexbuilder/withdraw-sign-data)的返回值一致。
- `Idempotency-Key` 必填，同一用户在此接口内重试相同 Key 时回放首次成功响应。`success=true` 表示请求已受理；最终状态通过[查询提现状态](/api-reference/dexbuilder/withdraw-status)获取。
