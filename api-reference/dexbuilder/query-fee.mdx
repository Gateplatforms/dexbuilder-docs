title: "查询费率"

---

`GET /api/v4/dexbuilder/fee`

查询当前 Broker 的永续合约相关费率。

此接口查询 Broker 配置，无需钱包地址；仍须使用 Broker API Key 签名。详见[认证与 API Key](/api-reference/dexbuilder/authentication)。

## 请求参数

| 参数 | 位置 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `x-gate-device-type` | header | 是 | string | 设备类型，须为 Perp 支持的枚举值（如 web）；示例：`web` |

## 响应

成功时返回统一结构：`code`、`message`、`data`、`trace_id`。`data` 包含以下字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `data.list` | array | 各链的费率列表 |
| `data.list[].chain` | string | 链标识 |
| `data.list[].deposit_fee` | string | 充值费率或费用，单位待确认 |
| `data.list[].withdraw_fee` | string | 提现费率或费用，单位待确认 |
