这里记录事件市场 API 的能力上线与接口更新。具体接入方式和参数以链接的 API 文档为准。

<Update label="2026-11-10" description="Broker API 与 K 线接口更新">
  ## 事件市场 API 更新

  ### Broker API 接入

  事件市场支持 Broker 使用 Broker API Key 访问私有 REST 接口。Broker 可代表旗下用户调用相关接口，并通过 `X-User-Wallet-Address` 指定用户钱包；公开行情接口无需认证。接入方式见[Broker API Key 与签名](/api-reference/common/broker-authentication)和[事件市场 API 概览](/zh/event-markets/api/overview)。

  ### K 线接口更新

  公开 K 线文档现推荐 `GET /api/v4/prediction/crypto/candlesticks`。与原文档中的 `GET /api/v4/prediction/tokens/{currency}/candlesticks` 相比，新接口使用查询参数 `symbol` 和必填的 `interval`，时间范围使用 `start_ts/end_ts`；成功响应由 K 线数组改为包含 `symbol`、`interval`、`history` 等字段的对象。`tag_id` 暂时兼容，与 `symbol` 必须二选一。旧接口仍保留供现有调用使用。详见[查询加密货币 K 线](/zh/event-markets/rest/query-candlesticks)。
</Update>
