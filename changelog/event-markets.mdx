这里记录事件市场面向 Broker 的能力上线信息。具体接入方式和接口参数以链接的 API 文档为准。

<Update label="2026-11-10" description="加密货币 K 线">
  ## 新增加密货币 K 线查询

  事件市场提供公开的币种 OHLCV K 线接口 `GET /api/v4/prediction/crypto/candlesticks`。新接入建议使用币种代码 `symbol`；`tag_id` 暂时保留兼容，两者必须且只能提供其中一个。时间边界及 `history[].t` 使用 Unix 秒；`interval=all` 不保证返回全部历史。详见[查询加密货币 K 线](/zh/event-markets/rest/query-candlesticks)。
</Update>

<Update label="2026-11-10" description="Broker API 支持">
  ## 事件市场支持 Broker API 接入

  事件市场已支持 Broker 使用 Broker API Key 访问私有 REST 能力。Broker 可代表旗下用户调用相关接口，并通过 `X-User-Wallet-Address` 指定用户钱包。公开行情接口仍可直接访问。

  本次同时提供 Broker API Key 的认证与签名说明。接入前请阅读[Broker API Key 与签名](/api-reference/common/broker-authentication)和[事件市场 API 概览](/zh/event-markets/api/overview)。
</Update>
