<Update label="生效日期待确认" description="币种 K 线查询">
  ## 新增加密货币 K 线查询

  新增公开接口 `GET /api/v4/event_contracts/crypto/candlesticks`，可按加密货币标签 ID 查询币种的 OHLCV K 线，无需 Broker API Key。

  - 使用 `tag_id` 指定币种，使用 `interval` 选择展示档位。
  - 可通过 `start_ts` 和 `end_ts` 限定查询范围。请求时间和 `history[].t` 均使用 Unix 秒。
  - 查询币种 K 线时，请使用此接口；Token 价格历史仍按其独立接口的说明查询。

  详见[查询加密货币 K 线](/zh/event-contracts/rest/query-candlesticks)。
</Update>
