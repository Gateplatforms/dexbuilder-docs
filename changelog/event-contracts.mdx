<Update label="发布日期待确认" description="Broker API 支持">
  ## 事件合约支持 Broker API 接入

  事件合约已支持 Broker 使用 Broker API Key 访问私有 REST 能力。Broker 可代表旗下用户调用相关接口，并通过 `X-User-Wallet-Address` 指定用户钱包。公开行情接口仍可直接访问。

  本次同时提供 Broker API Key 的认证与签名说明。接入前请阅读[Broker API Key 与签名](/api-reference/common/broker-authentication)和[事件合约 API 概览](/zh/event-contracts/api/overview)。
</Update>
