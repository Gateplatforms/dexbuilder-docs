  ## DexBuilder 平台 API 面向 Broker 开放

  DexBuilder 平台 API 已提供面向 Broker 的资产配置、用户查询、充值和提现能力。Broker 使用 Broker API Key 调用平台接口；代表旗下用户访问时，通过 `X-User-Wallet-Address` 指定用户钱包。

  本次同时提供 Broker API Key 的认证与签名说明。接入前请阅读[Broker API Key 与签名](/api-reference/common/broker-authentication)、[DexBuilder 平台 API 概览](/api-reference/dexbuilder/overview)和[平台 API 认证](/api-reference/dexbuilder/authentication)。
</Update>
